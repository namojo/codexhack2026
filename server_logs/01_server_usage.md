## 추가 외부 서비스와 규칙 검토

- OpenAI: 기존 ChatGPT 로그인 Codex CLI 추론(사용자 설정 모델 상속, 보존된 CLI 결과에서 구체 모델명 미확인), OpenAI API 텍스트·이미지·음성 전사. 제공된 크레딧 사용 승인 범위이며 별도 결제·요금제 업그레이드·자동충전은 수행하지 않았다. 실제 호출/거절을 프로젝트 모델 검증 기록에 구분했다.
- GitHub: 프로젝트 코드 관리·push 및 Actions 회귀 검사. 별도 공개 저장소의 공간/경로 기능을 통합했다.
- 공개 자료: 서울 열린데이터광장·OSM 도로/침수 자료, 소방청·OpenAI·Supabase·Netlify 문서, NIST·arXiv·Nature 연구 자료 열람. 학습·추론용 타사 모델 서버 사용 증거는 확인되지 않았다.
- 패키지/모델 자료: 기존 Whisper 설치·모델 다운로드가 보존 문서에 기록돼 있다. 기존 라이브러리 설치와 공개 데이터 다운로드를 외부 추론 서버 사용과 구분한다. 이 수집에서 모든 다운로드의 호스트/IP/세션을 확보하지 못했으므로 임의 서버명을 채우지 않는다.
- 로컬: macOS 합성 TTS·NumPy DSP·개발 서버. 외부 서버가 아니며 로컬 상태를 관리형 서비스 OS로 대체하지 않는다.
- 첨부 가이드는 증빙 제출 규격 **초안**이며 외부 서비스별 허용/금지 목록·제재를 규정하지 않는다. 확보한 자료만으로 해커톤 규칙 위반 서버를 확정할 수 없다. 전체 공식 행사 규칙 또는 운영진 확인이 필요한 항목은 위 OpenAI API·기존 자산·공개 데이터 사용 범위다. 이는 위반이 확인됐다는 뜻이 아니다.
