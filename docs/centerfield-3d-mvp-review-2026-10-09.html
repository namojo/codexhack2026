센터필드 주변 건물 도면 → 3D 위치 후보 목업

진행 결과와 사용자 추가 요청

더포엠 역삼(역삼동 677-12, 테헤란로33길 12)의 공개 3~16층 소개 평면도를 확보했다. Sol(gpt-6.1-sol)이 도면과 합성 이미지·문자를 읽어 가상 3층 B타입 3호 라인의 창가 주공간을 후보로 제시했다.

사용자 요청에 따라 3~16층 14개 층에 같은 배치를 반복한 개략 건물 투시도를 추가했다. 1~2층은 내부를 복원하지 않은 미확인 기단으로 표시한다. 층고·외형은 실측이 아니다. 층 탐색은 신고 위치를 변경하지 않으며 다른 층에는 후보를 그리지 않는다.

후보 설명과 인원 진술은 모델 밖 상태 카드로 옮겼다. 물음표 마커를 제거하고 짧은 라벨의 충돌을 검사한다. 독립 QA가 발견한 CSP 문제는 외부 JS/CSS 분리로 수정했다.

업그레이드한 공간정보 페이지 · 검증 기록

로컬 검토용이며 외부 배포하지 않았다. 자동 브라우저의 file URL 접근이 정책상 차단되어 실제 브라우저 검증은 미실행이다. 코드·데이터·캔버스 렌더 검사와 구분한다.

결론과 범위

별도 정적 페이지 하나로 구현 가능한 MVP다. 가장 큰 선행 조건은 대상 건물과 공개 도면의 일치 여부다. 최초 검토 때는 대상 건물을 확정하지 못했으나, 후속 구현에서 더포엠 역삼의 소개 평면도를 선정했다. 공개 재배포 권한은 미확인이다. 검색 결과의 ‘평면도’ 메뉴만으로 원본 도면 확보를 주장하지 않는다.

테헤란로에서 센터필드를 바라봤을 때의 후면을 우선 탐색 범위로 잡는 것을 제안한다. 실제 지도에서 위치를 확인하고 건물의 주소·건물명·층·평형을 대조한 뒤 선정한다. 건물 선택을 먼저 고정하기보다 공개 도면을 확보할 수 있는 건물부터 고르는 것이 효율적이다.

네 가지 작업의 산출물

  1. 대상 선정:주변 집합건물 후보를 지도에서 확인한다. 분양자료·공식 건축자료 등 원출처의 도면을 우선 찾는다. 주소, 해당 평형, 배치도, 도면 날짜와 이용 조건을 기록한다. 실제 도면을 못 찾으면 그 사실을 보고하고, 실재 건물에 합성 내부 구조를 붙이는 대안은 별도 선택사항으로 둔다.
  2. 3D 변환:Astra 또는 Sol이 도면을 읽어 방·벽·문·창·치수·연결관계를 구조화한다. 이를 검증하고 정적 3D 장면으로 만든다. 원본 평면도와 3D를 나란히 비교할 수 있게 한다. 모델 원출력과 사람이 수정한 항목을 보존한다. 치수가 없는 높이와 방향은 추정으로 표시한다.
  3. 합성 신고:가상 상황 이미지 한 장과 짧은 문장을 만든다. 예시 문장: ‘3층입니다. 거실에서 복도를 지나 창문 옆 작은 방에 두 명이 있습니다. 복도 쪽에 연기가 보여요.’ 실제 선정된 도면의 공간에 맞춰 수정한다. 모델에는 위치 정답을 주지 않고 도면·이미지·신고만 제공한다. 정답은 평가용으로 따로 보존한다. 결과는 후보 공간과 근거로 표시한다.
  4. 진입 유의사항:신고에서 관찰된 위험, 도면에서 확인한 공간 연결, 아직 모르는 현장 조건을 나눠 표시한다. 문 개방 여부, 공용 계단·복도 연결, 장애물, 도면 이후 변경 여부 등 확인사항을 제공한다. 도면과 신고만으로 안전한 진입을 확정하거나 실내 화재 전술을 만들지 않는다.

중요한 도면 범위

세대 내부 평면도만 확보하면 방과 방 사이의 위치 후보를 보여줄 수 있다. 건물 출입구에서 해당 세대까지의 접근을 표현하려면 동 배치도와 공용 계단·복도 도면도 필요하다. 세대 평면도 하나를 반복해서 실제 건물 전체를 복원했다고 표시하면 안 된다.

가상 신고의 층·호실은 합성임을 표시한다. 평형별 도면만 있고 실제 호실 대응표가 없다면 ‘가상 3층·해당 평형’으로 표현한다. 북쪽 방향이나 실제 방 좌표를 근거 없이 확정하지 않는다.

화면과 정적 동작

상단에 대상 건물·도면 출처·목업 표시를 둔다. 본문에는 원본 도면, 회전·확대 가능한 3D, 합성 신고 이미지와 텍스트, 강조된 위치 후보, 원문 근거와 유의사항을 배치한다. 방을 선택하면 관련 근거를 보여준다. 낮은 확신을 숫자로 꾸미지 않고 복수 후보 또는 판단 보류로 표현한다.

실행 시점에는 미리 만든 공간 데이터와 모델 결과를 읽는다. 실제 모델 호출은 사전 제작 단계에 한정한다. HTML과 로컬 자산으로 동작하고 API 키를 포함하지 않는다. 향후 실시간 시스템도 도면을 사건마다 새로 변환하기보다 검증된 공간 모델을 보관하고 신고·현장 상태를 갱신하는 구조가 적합하다.

검증과 완료 조건

  • 원출처 도면과 대상 주소·평형의 일치를 확인한다.
  • 3D 벽·문·방 연결을 원본 도면과 대조하고 추정 치수를 표시한다.
  • 이미지를 실제 분석했는지와 모델 실행 결과를 기록한다. 사람의 사전 배치를 모델 추정으로 표시하지 않는다.
  • 모호한 신고 또는 충돌 단서가 들어오면 후보 확대·판단 보류가 표시되는지 확인한다.
  • 실제 브라우저에서 회전·확대·공간 선택·모바일 레이아웃·근거 표시를 확인한다.
  • 제품 계약의 기존 범위와 공간 지원 확장의 관계를 문서화한다. 공개 배포는 별도 범위로 다룬다.

합성 이미지를 도면에 맞춰 만들면 데모의 정합성은 확인할 수 있지만 실제 신고 이미지 인식 성능은 증명하지 못한다. 실시간 변환 성능, 실제 건물 최신성, 현장 구조 효과도 이 목업의 검증 범위에 포함되지 않는다.

확인한 자료와 미확인 사항

S-Map 사용가이드는 건물·실내지도 조회를 안내한다. 세움터는 건축물현황도 발급·열람 요건을 안내한다. 해당 절차를 대신 신청하거나 승인 없이 도면을 수집하지 않는다.

초기 검색에서 주변 주거건물 평면도 관련 결과는 있었으나 이번 검토에서는 지도 위치·도면 원본·이용 조건의 동시 검증을 마치지 않았다. 대상 건물 확정은 구현 착수 후 첫 번째 진행 조건이다.

지정 검토 폴더의 README가 앞선 확인에서 존재하지 않아 쓰기가 허용된 프로젝트 docs/에 보존했다. 별도 공간 페이지·로컬 제공 경로·메뉴·전용 계약을 추가했다. 기존 엔진·업무 상태와 전역 모델 설정을 변경하지 않았고 외부 배포하지 않았다.
