## 출처와 자체 설계의 경계

공개 출처가 확인하는 것은 다양한 신고 채널과 공개 안내·서식의 존재다. 건물 안 다른 가구의 개별 ID 보존, 사람이 하는 중복 연결, revision 기반 오래된 승인 차단, 미확인 알림과 완료 근거 대조는 이 프로젝트의 자체 계약이다. 공개 안내에 근거해 공식 상황실도 동일하게 동작한다고 추정하지 않는다.

앱 GPS가 신고자 위치를 가리킨다는 공개 설명에서 **대리 신고 시 구조 대상 위치와 달라질 수 있다**는 검증 사례를 설계했다. 이는 프로젝트의 위험 가설이며 실제 119 처리 오류의 관측 결과가 아니다. 합성 좌표 0.001/0.002는 테스트용 가공 값으로 실제 신고 위치가 아니다.

## 재현·표현·저작물

모든 사례는 synthetic으로 표시하며 실제 개인정보·신고 기록을 넣지 않았다. 사진·영상은 직접 생성한 텍스트 설명, 영상통화는 인간이 작성한 모의 전사다. `fixture_analysis`도 인간작성 분석이며 실제 LLM·OCR·ASR 결과가 아니다. 모델 정확도, 실사용 생존율, 시간 절감, 처리량 개선은 이 재생으로 측정하지 않았다.

참고 페이지의 이미지·영상·서식 전체를 복제하지 않고 링크와 제한된 사실 요약만 사용한다. 정책브리핑 2024 카드 자료에는 텍스트 공공누리 제4유형, 2023 기사에는 제1유형 안내가 표시되며, 각 페이지는 이미지·영상의 별도 권리 확인을 안내한다. 본 프로젝트 합성 사례 원문은 출처의 실제 신고를 옮긴 자료가 아니다.

## 서비스 콘솔 v2의 매체·업무 근거

`data/media/`에는 빌트인 image_gen으로 생성한 사진 2장과 macOS 한국어 TTS WAV 2개가 실제 파일로 들어 있다. 프롬프트·합성 신고 대본은 `provenance.json`에 저장했다. 위 v1 재생기의 '첨부 설명/모의 전사'와 구분한다. 이 파일의 존재는 OCR·ASR 실행 증거가 아니다.
공개 상황실 업무와 규정 조회 범위는 [서비스 근거 문서](service-rationale.md)에 정리했다. 서비스 UI는 자체 제안이며 공식 내부 대시보드나 API를 복제하지 않았다.
