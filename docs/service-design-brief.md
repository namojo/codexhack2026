# 업무 콘솔 디자인 브리프
주사용자: 다매체 신고를 접수·대조하고 현장팀에 정보를 인계하는 상황실 담당자. 공공 자료의 접수/관제 업무를 참고한 제안 UI이며 공식 내부 화면 복제 아님.
첫 화면: 하루 업무 대시보드, 진행 건 목록과 확인 필요한 사건을 바로 찾는다. 헤더 '아직 여기 / 신고·구조 상황관리', 작게 합성 훈련 데이터. 사이드바 업무 메뉴(상황 대시보드·진행 사건·처리 결과·검증 도구). 주영역 운영 요약→상태/검색 필터→사건 테이블, 측면 가용 자원·인계 확인. 과한 영웅 제목·발표 카운트·예상 테스트 노출 금지.
사건 상세: 돌아가기·번호·상태·우선도·수정; 위치·인원·팀; 세 영역 접수 원문 및 미디어 / 대조·미확인 사항 / 현장 진행 및 결과. 타임라인 최신순, 원문·출처·접수시간, 실제 사진 확대와 음성 재생. 업무 액션 '추가 정보 등록', '진행 변경', '처리 결과 확인'. 필수·선택·입력 오류 명확히. 종료에는 근거 현장보고와 확인인원. 이력 탭/영역에서 원문과 변경 사유 지속보존.
토큰: 배경 #f3f5f8, 패널 #fff, 기본 남색 #183449, 주요동작 #225e9e, 경고 #9b650c 배경 #fff4d6, 완료 #197363. 본문 14px 한글 시스템서체, 표 13px, title24px, 간격8/12/16/24, radius6. 눈에 띄는 장식·큰 gradient·과도한 rounded카드 금지. 경고는 텍스트와 출처 함께, 담당자 우선도와 구조 사실 구분. 모바일에서는 목록→상세 독립, 버튼 wrap. loading/empty/error, 폼 reset/취소, 키보드 focus, Escclose, toast aria-live.
