출동경로 검토 페이지

기존 콘솔에 출동경로 안내 메뉴를 추가했습니다. 실제 공개 도로 좌표를 사용하고, 합성 요청 3곳에 대한 최단 비교와 차량 접근 조건을 반영한 훈련 경로, 과거 침수 이력을 고려한 추가 경로를 보여줍니다.

지역과 자료

서울시가 상습 침수 이력을 설명한 신림동 도림천 주변을 선정했습니다. 출발 시설은 관악로 97의 관악소방서입니다. 목적지는 신원시장 주변 공개 도로 위의 합성 접근 지점입니다. 실제 피해 주민이나 특정 가구를 뜻하지 않습니다.

2026-10-09 내려받은 OpenStreetMap 도로망에서 5,682개 노드, 12,210개 방향 구간, 34개 단일 교차점 회전 제한을 추출했습니다. 보행로·계단·공사 도로와 명시적 통행 금지 구간은 차량 계산에서 제외합니다.

소방서 부지 중심과 도로 출발점 사이 거리는 약 53m입니다. 실제 차고 출입구를 확인하지 못했으므로 이 구간을 직선 운행 경로로 만들지 않습니다. 마지막 건물 접근도 모델에 포함하지 않습니다.

실제 침수흔적도와 추가 경로

서울시 공식 침수흔적도의 2010~2025 제공 14개 연도 ZIP을 내려받았습니다. 자료 갱신일은 2026-04-27입니다. 공공누리 1유형에 따라 출처를 표시하고 좌표를 변환했습니다. 2015·2021은 서울시가 침수 없는 연도로 안내하여 파일이 없습니다. 2026년 자료는 포함하지 않습니다.

이 지도 영역의 기록 연도는 2010·2011·2022·2023·2024입니다. 파일명 대신 F_YR 침수년도 속성으로 분류하고 같은 연도 영역의 합집합을 계산했습니다. 2022 ZIP 안의 일부 2023 기록도 2023으로 분류합니다. 주소·PNU·피해 원문 속성은 공개 결과에 넣지 않았습니다.

실제 등록 영역과 주변 10m 가정 범위를 다른 색으로 표시합니다. 연도 선택은 레이어와 경로 계산에 함께 적용합니다. 표시 체크를 끄면 레이어만 숨기고 경로 계산은 유지합니다.

추가 경로는 차량 폭·높이·양측 여유와 통제·통행 조건을 그대로 적용하고, 기존 권고 비용에 선택 연도별 주변 통과 길이의 합 × 8을 더합니다. 같은 연도 중복은 한번만 계산하고, 여러 연도 기록은 각 연도로 더합니다. 10m와 8은 훈련 가정이며 통계적 침수 확률을 뜻하지 않습니다.

침수흔적도는 과거 피해 등록 범위입니다. 현재 침수·도로 수심·미래 침수 확률이 아닙니다. 기록이 없는 곳도 안전을 보장하지 않습니다. 조사 누락·강우·수위·배수시설 개선·지형 고도·교량의 수직 차이를 모델링하지 않습니다. 과거 침수는 통제와 달리 완전히 제외하지 않으므로 목적지 접근에 잔여 노출이 남을 수 있습니다.

원본 PRJ를 읽어 EPSG:5179 미터 좌표에서 실제 도로 중심선의 교차 길이를 계산하고 EPSG:4326 경위도로 표시합니다. 원본 영역을 단순화하지 않습니다. 14개 ZIP SHA256, 원본 좌표계, 선택·보정 건수와 도로망 지문을 JSON meta에 저장했습니다. 같은 원본으로 재생성한 파일은 바이트까지 동일했습니다. 원본 피해주소 DBF와 전체 ZIP은 Git에 올리지 않습니다.

‘현장 확인값만 사용’ 모드는 검증된 유효폭이 없는 길을 제외합니다. 현재 확인값은 0개이므로 경로 없음이 정상입니다. 이전 훈련 권고를 그대로 유지하지 않습니다.

사용 방법과 저장 범위

  1. 프로젝트에서 python3 -B scripts/serve.py --port 8765를 실행합니다.
  2. 콘솔의 출동경로 안내 메뉴를 엽니다.
  3. 합성 접근 지점과 차량 폭·높이·좌우 여유를 선택합니다.
  4. 훈련 권고와 최단 비교, 구간별 도로 안내를 확인합니다.
  5. 가상 침수 통제 또는 현장 확인값 모드로 결과 변화를 확인합니다.

계산은 브라우저에서 결정적으로 수행합니다. API 키와 외부 지도 타일, 추가 모델 호출을 사용하지 않습니다. 기존 사건 DB를 수정하거나 실제 출동을 요청하지 않습니다.

구글맵과 네이버지도 링크를 누르면 목적지 좌표 또는 검색어가 해당 서비스에 전달됩니다. 내부 차량·침수 조건과 권고 경로는 전달되지 않습니다.

정적 검토용 패키지: python3 -B scripts/build_pages.py --include-routes --output dist/routing-preview. 외부 게시 기능을 실행하지 않습니다. 기본 공개 빌드에는 경로 페이지를 추가하지 않습니다.

결정·복구·한계

이번 변경은 새 경로 엔진·페이지·공개 도로 스냅샷을 추가하고 서버의 정적 파일 허용표와 콘솔 메뉴, 정적 패키지 옵션을 확장합니다. 기존 신고·원문·처리 상태 계약은 유지합니다.

변경 전 Git 상태는 _workspace/routing-v1/baseline-status.txt에 기록했습니다. 사용자가 이미 수정한 역할 설정과 조사 문서는 보존했습니다. 사용자 DB를 변경하지 않으므로 DB 복구 작업은 필요하지 않습니다. 코드 복구 지점은 기본 경로 커밋 4313490과 침수흔적도 커밋 53da70e입니다. 원격 AI·공간정보 변경은 11063e9까지 정상 병합했고 최종 제품 검사는 b55ed8c 기준입니다. 기존 로컬 설정 13개가 원래 파일 지문과 같은 것을 확인했고 복구용 stash도 보존했습니다. Git push 목적지는 저장소 main입니다. 최종 원격 일치와 자동 검사 결과는 채팅에 보고합니다.

공개 도로망 밖의 경로, 실제 차량 통과성, 현재 재난·교통 상태, 실제 구조의 성공 여부를 보증하지 않습니다. 최종 운행에는 장비 제원과 현장 통제·도로 유효폭·회차 확인이 필요합니다.
