## 실제 브라우저 수행

- 현재 주소 `http://127.0.0.1:8765/`: 대시보드 상위3건, 전용 메뉴 전체6건, 즉시 확인2건·판단 필요3건·후속 확인1건. 완료008·009·011은 현재 조치 카드에서 제외한다.
- 진행 사건은003의 인원 대조를 먼저 표시한다. 처리 결과와 대응 자원에서도 현재 미처리 사건의 공통 알림을 볼 수 있다. 상세와 전용 메뉴도 동일 알림을 유지한다.
- 원문 버튼으로 REP-003-03에 이동하고 포커스를 확인한다. 카드의 현재 상황은 접수3명/현장2명, 이유는 미확인1명, 다음 업무는 새 현장 보고다.
- 임시 DB/8766에서 신규 접수 → 카드의 진행 변경 → TEAM-04 배정 → 배정 과제 해소 → 2명 부분 보고 → 즉시 확인 과제 → 카드의 현장 보고 버튼 → 3명 전원 보고 → 인원 과제 해소 → 담당자 결과 확정 → 새로고침 보존을 수행한다.
- 최종 코드로 서버를 재시작한 뒤 완료 기록 보존을 확인하고, 재개 → 새 부분 보고 → 새 전원 보고 → 다시 확정까지 재검증한다. 재개 전 보고는 현재 근거가 되지 않으며 ‘남아 있는 사람은 없습니다’가 잔여 대상 경고로 남지 않는다.
- 390×844에서 문서폭375, 카드폭343, 입력 창폭341로 문서 가로 넘침이 없다. 카드에서 입력 창을 열고 취소를 확인한다. 반응형 설정은 검사 후 해제한다.
- 사용자 기존 DB는 수정·삭제·초기화하지 않았다. 실제 시연 입력은 `/private/tmp/attention-browser-v4.sqlite3`에만 남겼다. 임시 서버/탭은 종료하고 업무 서버는8765에 유지했다. 열려 있던 두 업무 탭도 새 화면으로 갱신했다.

## 실행 분담과 미실행

기존 실제 유휴 작업자 `/root/engine`은 backend, `/root/cases`는 frontend, `/root/qa`는 이번 backend/frontend 제작에 참여하지 않은 독립 테스트를 맡았다. 프로젝트 역할 파일을 읽어 기존 에이전트를 재사용했으며 자동 native 역할 로딩이나 새 컨텍스트 생성으로 주장하지 않는다. QA는 이전 seed 제작자이므로 자기 seed의 독립 검증을 주장하지 않는다. 이번에는 seed를 변경하지 않았다. 실제 브라우저는 메인이 수행했고 QA는 증거를 별도로 검토했다.

미실행: 실제 LLM/OCR/ASR, 실제119연계, 실제 피해자의 신고, 운영자 현장 사용성 및 대응 시간/구조 성과 측정. 규칙은 지정한 합성 사례의 확인 과제를 만드는 범위이며 자연어 의미를 일반적으로 이해하는 모델로 검증되지 않았다.
