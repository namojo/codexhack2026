# 발표 화면 구성

대상: 해커톤 심사위원과 구조 상황실 담당자. 가장 먼저 보여줄 내용은 현재 사건의 원문, 아직 확인되지 않은 요청, 다음 확인 질문이다.

색상: 종이 흰색 #ffffff, 차가운 배경 #eef3f7, 본문 남색 #173246, 보조 글자 #526878, 확인 필요 황갈색 #86550a, 확인 완료 청록색 #166653. 위험은 색과 문구를 함께 표시한다. 경보용 빨강은 거절/차단에만 사용한다.

서체: macOS의 Apple SD Gothic Neo 및 시스템 한글 고딕. 외부 폰트 로딩을 없애 오프라인 데모에서 일관되게 표시한다. 큰 제목보다 현장 원문과 질문에 계층을 둔다.

배치: 왼쪽에는 사례 선택 목록, 중앙에는 요청별 현황, 오른쪽에는 현재 원문과 대조 근거를 둔다. 사건 진행은 상단의 고정 컨트롤로 조작한다. 모바일에서는 사례 선택과 진행 조작, 요청 현황, 원문 순서로 쌓는다.

```text
브랜드 / 합성 데이터·분석 모드
사례 목록 | 사례 설명 / 이전·다음·초기화
          | 미확인 요청 현황 | 현재 사건과 첨부 설명
          | 다음 확인 질문  | 연결된 원문 근거
          | 기대값 검사·사건 기록
```

큰 지도, 위험 점수, 자동 재생은 넣지 않는다. 실시간 현장처럼 보이는 장식 대신, 각본의 사건이 언제 처리됐는지와 요청별 상태 변화가 눈에 보이도록 한다. 자료가 실제 사진이 아니면 `합성 첨부 설명`을 표시한다. 모의 담당자 결정은 `각본의 담당자 결정 적용`으로 명명한다.

접근성: 키보드 focus, 명확한 버튼 이름, 텍스트 상태, 충분한 대비, 390px 모바일에서 가로 스크롤 방지, 동작 감소 설정 준수.
