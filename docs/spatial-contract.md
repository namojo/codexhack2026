## v2 사용자 추가 요구 — 2026-10-09
3~16층 동일 평면 가정으로 14개 층을 반복한 개략 건물 투시도. 1~2층은 미확인 기단이며 내부를 복원하지 않는다. 지하·옥상 구조는 미모델링. 층고·형상은 표시용 가정이다. 층 선택은 카메라/도면 탐색이며 신고 위치 변경이 아니다. 다른 층에서는 후보 영역을 그리지 않는다. 신고는 가상 3층에 유지한다. 건물 전체/선택 층 입체/평면, 신고 위치 보기, 초기화 지원.
후보 설명과 인원 진술은 캔버스 밖의 고정 상태 카드에 표시한다. 물음표 마커 제거. 캔버스 라벨은 짧게 표시하고 경계·라벨 간 충돌 검사를 거쳐 배치한다. 다른 위치·높이에서 반복한 층은 모델의 새 분석 결과가 아니라 사용자 승인된 반복 가정이다.
실제 브라우저 file:// 검사는 도구 정책으로 차단되었으며 우회하지 않는다. 정적·Node 모의 기능 검사와 캔버스 프로그램 렌더 검사로 구현을 점검하고 실제 브라우저 검증은 NOT_RUN으로 보고한다.

## v4 건축 모형 디자인 개선 — 2026-10-09
사용자가 디자인 검토 후 개선을 승인했다. 공간 전용 HTML·JS·CSS에서 두께 있는 입체 면, 면 방향 명암, 픽셀 깊이 버퍼, 개략 접점 음영을 사용한다. 넓은 화면에는 전체 건물과 선택 층 절개 모형을 함께 표시한다. 좁은 화면에서는 기존 버튼으로 전환한다. 라벨의 경계·충돌 검사를 유지하며 창가 후보 라벨을 외부 연결선으로 표시한다.

외벽 개구부와 B3 욕실 구획의 표시 좌표는 보관 도면(1120×745)에 직접 대조한 근사값이며 app.js의 architecture에 보관한다. 원 모델 JSON은 덮어쓰지 않는다. 문짝 각도·벽 두께·층고·창 높이·계단 단차·재질은 표시 가정이고, 문 상부를 생략한 절개 모형임을 화면에 명시한다. 다른 세대 내부 구획과 저층부·옥상 상세는 복원하지 않는다. 반복 창은 평면 기반 설명용 외형이며 실제 입면 복원 결과가 아니다. 새 모델 호출·외부 라이브러리·전송·실제 배포는 추가하지 않는다.


## v5 1인칭 이동 영상 — 2026-10-09
사용자 요청으로 3층 계단 도착부→복도→B3 현관→주방 옆→창가 후보까지 이어지는 28초 설명 영상을 추가했다. 실내 진입 후 약15초 연속 이동하며 최종 카메라 위치는 기존 후보 영역 내부다. 영상은 가상3층 고정이며 위쪽 모형의 층 선택과 분리한다. 실제 출동·통과 가능·구조 완료 판단이 아니다.

영상 형상은 app.js의 기존 면 데이터를 시점별 제거 이전에 추출해 재사용한다. 원본 도면에서 계단실로 연결되는 홀을 막지 않도록 복도 남측 벽의 끝점을 정정했다. 설명용 천장·문 개방·높이·재질·시선은 가정이다. 현관 흐림은 신고 근거가 있는 위치 주석이며 실제 연기나 농도를 재현하지 않는다. 계단·문·장애물·유효 폭 등은 현장 확인 필요로 구분한다. 실제 인물 모델을 추가하지 않는다.

MP4·포스터·한국어 VTT·생성 JSON을 공간 전용 공개 allowlist에 추가한다. 자동 재생 없이 네이티브 영상 제어와5구간 이동을 제공한다. 로컬 서버는 MP4 byte range를 지원하고 기존 API를 변경하지 않는다. 원본 도면 JPEG의 공개 제외 조건을 유지한다. 새 모델 호출·외부 영상 생성 서비스·외부 배포 없음.
