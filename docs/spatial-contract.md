## v2 사용자 추가 요구 — 2026-10-09
3~16층 동일 평면 가정으로 14개 층을 반복한 개략 건물 투시도. 1~2층은 미확인 기단이며 내부를 복원하지 않는다. 지하·옥상 구조는 미모델링. 층고·형상은 표시용 가정이다. 층 선택은 카메라/도면 탐색이며 신고 위치 변경이 아니다. 다른 층에서는 후보 영역을 그리지 않는다. 신고는 가상 3층에 유지한다. 건물 전체/선택 층 입체/평면, 신고 위치 보기, 초기화 지원.
후보 설명과 인원 진술은 캔버스 밖의 고정 상태 카드에 표시한다. 물음표 마커 제거. 캔버스 라벨은 짧게 표시하고 경계·라벨 간 충돌 검사를 거쳐 배치한다. 다른 위치·높이에서 반복한 층은 모델의 새 분석 결과가 아니라 사용자 승인된 반복 가정이다.
실제 브라우저 file:// 검사는 도구 정책으로 차단되었으며 우회하지 않는다. 정적·Node 모의 기능 검사와 캔버스 프로그램 렌더 검사로 구현을 점검하고 실제 브라우저 검증은 NOT_RUN으로 보고한다.

## v3 공개 서비스 통합 — 2026-10-09
