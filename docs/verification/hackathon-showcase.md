# 대표 지하주차장 사례 검증

2026-10-09 합성 태풍 침수 대표 사건 `INC-20261009-100`과 별도 중복 후보 `INC-20261009-101`을 추가했다. 원래 10사건·20보고·4팀은 보존했고 seed는 12사건·30보고·5팀이다. 공유 DB에는 이전 별도 검증사건을 포함한 기존 11사건을 보존하고 새 2건만 추가해 13사건이 됐다. 대표 사건은 구조 진행·전체3명·현장2명·결과 미확정 상태를 유지한다.

- 사진: built-in image_gen으로 PNG2장 생성·육안 검수. 기둥 B2/C07와 침수 계단을 표현하며 실제 재난 사진이 아니다.
- 음성: macOS 한국어 TTS·합성 잡음, 잡음 입력에 STFT DSP를 적용한 비교 PCM WAV. 각16.272초, 22050Hz mono. 제작 대본과 실제 ASR를 분리했다. [생성 기록](../../data/media/provenance.json).
- 독립 실제 Vision: 주소·GPS·기둥 번호가 없는 원문과 기둥 PNG만 넣고 기존 사건 텍스트를 제외했다. [사진만의 실행](showcase-vision-live.json)에서 B2/C07을 실제 이미지 관찰 근거로 기록했다. 위치 검증은 unverified, 주소/GPS는 null이며 단일 합성 사진의 인식 결과다.
- 실제 OpenAI: 사진2장·음성2개·현장 추가 보고와 보존 원문을 넣어 구조화 분석했다. [성공 초안](showcase-ai-live.json), [실제 전사 비교](showcase-asr-comparison.json). 잔류1명을 제안하고 전체 접수 인원 제안은3명으로 유지했다. 초안은 사건 변경 또는 담당자 확정 결과가 아니다.
- 실패: 초기 강한 잡음 ASR는 빈 전사를 반환했다. 최종 잡음 강도로 재검증한 중간 출력들은 원문 인용 변형·텍스트 관찰 혼용·필드 근거 누락으로 거절됐다. [보존한 실패 실행](showcase-ai-failures.json). 잘못된 초안을 fixture로 대체하지 않았다. 실제 원문 출처별 인용 스키마로 제약하고 동일 검증을 유지했다.
- 모델 한계: 성공 실행의 원음·DSP 전사 모두 `가상동`을 `가산동`으로 오인했다. 띄어쓰기·세 명/3명 차이도 남는다. DSP의 ASR 정확도 향상이나 화자 분리를 증명하지 않는다. 원문 대조와 위치 확인이 필요하다.
- 실제 로컬 브라우저: 진행 목록 첫 사건 확인, 사진 확대, 두 audio 모두16.272초 재생 완료, 2명 현장 근거로2명/3명 완료 요청 모두 거절, 입력 보존·취소 후 구조 진행 유지, 별도 공간·경로9메뉴 이동 확인. [사진 확대](../images/showcase-pillar.png), [완료 차단](../images/showcase-completion-blocked.png).
- 독립 QA: Python124, AI50, Codex23, Pages21, 대표 Node6, 기존 경로·엔진·fixture20/91 회귀. 8MiB+1 업로드 오류를 발견·수정 후413거절, 실제 PNG 업로드 바이트 보존 확인. 결정적 재생·모의 네트워크 검사는 실제 모델 정확도나 인명 구조 효과 증거가 아니다.
