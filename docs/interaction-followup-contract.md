# 서비스 v6 배정 입력창 보완

service-v5의 넓은 선택 영역과 버튼 배치를 그대로 유지한다. 실제 브라우저에서 대응 자원 > 가상 지원팀 > 사건 선택 > 팀 배정을 누르면 상세로 이동하지만 진행 입력창이 사라졌다. location.hash 변경과 명시 route(false)의 중복 실행에 따른 loadToken/incident 초기화 경합이다.

frontend는 web/app.js의 assign-resource 업무 흐름만 보완한다. 기존 openAttentionWork와 일관된 단일 라우팅을 사용하고 선택한 사건과 팀이 유효한 상세에서 진행 입력창을 한 번 연다. 입력창을 여는 것은 저장이 아니며 취소하면 사용자 DB 변화가 없어야 한다. 다른 카드·행·탭·CSS 변경은 보존한다. 실제 브라우저는 메인이 검증하고 제작자와 독립 QA는 실제 구문 및 기존 회귀 검사와 수정 범위를 검토한다. 새로 구현을 따라 쓰는 테스트를 추가하지 않는다. v5의 결함 기록은 보존하고 v6에서 재검증한다.
