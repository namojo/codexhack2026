결론

시제품은 만들 수 있다. 권장 순서는 주변 접근 조건 지도 → 건물·층 위치 후보 표시 → 확보한 도면으로 실내 공간 표시다. 건물 형상과 신고 문장을 결합하면 위치 후보를 표현할 수 있다. 실제 사람의 현재 위치, 도로의 현재 통행 가능 여부, 안전한 진입 방법은 별도의 현장 근거가 필요하다.

서울 전역 주택의 실내 도면과 실시간 골목 주정차를 공개 데이터만으로 확보할 수 있다고 가정하면 안 된다. 3D를 만들 수 있는지보다 입력 자료의 확보·정합성·최신성이 큰 제약이다.

건물과 사람의 위치를 표현하는 방법

  1. 주소를 건물 ID와 연결한다. 동일 주소의 여러 동, 반지하, 층 표기 차이를 보존한다.
  2. 건물 외곽과 높이가 있으면 외부 3D 형상을 사용한다. 층고가 없으면 층 구획을 개략 표현하고 추정임을 표시한다.
  3. 원본 BIM/IFC가 있으면 공간·층·계단·문 정보를 파서로 읽는다. 벡터 도면은 선과 치수를 처리하고, 스캔 도면은 OCR·선 검출·모델 해석을 결합한다.
  4. 도면의 축척·치수·방향·좌표계·층 연결·작성일을 검증한다. 2D 평면도만으로 창 높이, 벽 높이, 구조 성능까지 복원할 수는 없다.
  5. 신고 원문에서 건물·층·호실·주변 단서를 추출하고 검증된 공간 ID에 연결한다. 층만 알면 층 전체를, 방향만 알면 후보 구역을 표시한다. 근거 없이 방 중심에 점을 만들지 않는다.
  6. 화면에는 신고 진술, AI 후보, 담당자 확인을 구분한다. 원문·발생시각·수신시각·충돌 근거를 붙인다. 확인된 위치도 해당 시점의 위치임을 표시한다.

예시: “3층, 계단을 올라가 오른쪽 방”은 도면 방향과 계단 위치가 일치할 때 후보 공간을 좁힐 수 있다. “201호”라는 호실 이름만으로 남쪽 방이나 창문 위치를 알 수는 없다. 실내 GPS도 방 단위 확정 근거로 쓰기 어렵다.

Astra 또는 Sol은 도면의 표기 해석, 신고 단서 추출, 후보 연결 이유와 추가 질문 작성에 사용할 수 있다. 수치 좌표·3D 형상·경로 계산은 검증 가능한 프로그램이 맡는 설계가 적합하다. 두 모델의 실제 성능·비용·지연은 측정하지 않았으며 우열을 단정하지 않는다. 동일 입력으로 공간 연결 정확도, 근거 없는 추정, 판단 보류, 응답시간을 비교한 후 선택한다.

도로 접근과 주정차 판단

도로를 연결망으로 만들고 출발지에서 건물 출입구 또는 마지막으로 검증된 접근 지점까지 후보 경로를 계산한다. 차량의 폭·높이·회전 조건, 도로의 유효 폭·높이 제한·경사·회전 여유·통제 정보를 적용한다. 정보가 없는 구간은 ‘접근 조건 미확인’으로 표시한다. 일반 승용차 경로를 소방차 진입 가능 경로로 표시하지 않는다.

집중호우 사례에서는 교통 속도가 정상이어도 침수·유실·낙하물 때문에 진입할 수 없다. 실시간 침수 근거가 없으면 도로소통 정보로 안전을 추정하지 않는다. 차량 접근과 건물 내부 이동은 서로 다른 검증 문제다.

과거 단속 이력은 ‘주정차 장애 현장 확인 우선 구간’을 고르는 보조 자료다. 단속이 많은 곳은 단속 활동이 많았던 곳일 수도 있다. 현재 장애물은 최근 현장 사진·대원 보고·허가된 영상 등으로 확인해야 한다. 사진에 차량이 보여도 단일 영상의 원근만으로 통과 가능한 폭을 정밀하게 계산하지 않는다.

사전 확인사항 예시: 진입로 현재 사진 요청, 출입구와 차단기 개방 여부 확인, 유효 폭 측정 요청, 관할 담당자에게 통제·차량 이동 협조 필요성 검토. 시스템은 제안과 담당자 결정을 기록한다. 실제 협조 요청·차량 이동·출동은 자동 실행하지 않는다.

권장 시제품과 단계별 진행 조건

  1. 자료 점검:서울의 작은 구역을 선정한다. 도로 원본, 건물 ID, 출입구 좌표, 지도 재사용 조건, 갱신일과 API 응답을 확인한다. 골목 누락이 크면 출입구까지의 경로 제공을 보류한다.
  2. 최소 시제품:2D 접근 지도와 개략 3D 건물, 층별 요청 카드, 후보 경로, 미확인 구간, 주정차 단속 이력, 최신 현장 보고를 함께 보여준다. 도로·건물 공개 자료와 합성 구조 요청을 결합한다. 정밀 실내 모델은 필수로 두지 않는다.
  3. 실내 확장:사용 권한과 최신성이 확인된 건물 몇 개의 도면 또는 합성 도면을 사용한다. 도면을 검토하여 공간 연결망을 만들고 위치 후보를 표시한다. 실제와 합성 도면을 명시적으로 구분한다.
  4. 현장 적용 검토:관계기관과 데이터 제공·갱신·검증 책임을 정하고 운영자 비교 실험을 한다. 잘못된 건물 연결, 오래된 도면, 정보 누락 시 동작을 검증한 뒤 적용 범위를 판단한다.
