# 대표 합성 사례 — 지하주차장에 아직 남은 한 명

태풍·폭우·해일로 신고가 몰리는 상황에서, 여러 채널의 정보를 이어 읽고 안전이 확인되지 않은 사람을 다음 확인 업무로 남기는 데모다. 허리케인 등 국제적 자연재해에도 같은 문제를 적용할 수 있다는 제안이며 실제 재난 통계나 구난 효과 수치는 사용하지 않는다. 모든 인물·주소·신고·현장 자료는 synthetic이고 공식 119 접수·출동과 연결되지 않는다.

대표 사건 **INC-20261009-100**은 `demo_featured:true`인 발표 사례다. 위치는 가상동 한빛길 31 한빛복합센터 B2, 기둥 B2-C07 인근이며 확인이 필요하다. 신고자 진술과 사진 표기는 위치 후보다. 좌표, 공식 건물 DB, 공간 목업, 경로 데이터와 자동 연결하지 않는다. 발표 표시와 정렬은 데모 선택 이유이며 AI 긴급도 점수 또는 위험 순위가 아니다.

여성 세 명은 고령 여성 한 명, 여자아이 한 명, 성인 여성 한 명이다. 고령 여성과 여자아이 두 명은 현장팀이 구조했다고 보고했고, 성인 여성 한 명은 이후 문자로 잔류를 알렸다. 현재 `people_count=3`, `status=rescuing`, `outcome=null`, `revision=11`이다. **부분 구조 2명을 원 요청 3명의 완료로 바꾸지 않는다.** 같은 요청 세 명 전원에 대한 새 현장 근거와 담당자 확인이 필요하다. 가상 구조데모팀 `TEAM-DEMO01`은 4명이며 이 사건에만 배정돼 있다.

## 중복 후보와 사람 확인

별도 사건 **INC-20261009-101**은 가족 전언과 SNS 전달 원문 두 개를 가진 `status=received`, `people_count=null`, `assigned_team_id=null`, `revision=2`의 사건이다. 건물 이름이 같고 원 신고자도 재전달을 언급했지만 동일인 여부는 미확정이다. 원 사건 ID·중복 후보 ID·각 보고 ID를 그대로 유지한다.

담당자는 가족에게 원 신고자와의 관계·전체 인원·층을 묻고 SNS 원 작성자를 확인한다. 동일인 근거를 확인하기 전 자동 병합, 인원 합산·차감, 중복 후보에 추가 팀 출동을 수행하지 않는다. 바깥 신고자의 위치를 지하 구조 대상 위치로 자동 덮어쓰지 않는다. 현재 데모에는 사건을 자동 병합하는 기능이 없다.

미디어 파일과 생성·처리 provenance는 메인이 생성하고 검증한다. 경로가 문서나 seed에 있다는 사실만으로 파일 생성·재생 성공을 주장하지 않는다. 첨부 metadata는 기존 `id/url/filename/media_type/caption/source/transcript`만 사용한다. 이미지 caption은 생성 의도와 제한을 표시한다. 화면에 보이는 결과·모델이 본 결과는 실행 증거를 통해 확인한다.

두 WAV의 `transcript`는 다음 **합성 제작 대본**이며 실제 ASR 출력이 아니다.

> 여기는 가상동 한빛복합센터 지하 이층 주차장이에요. 기둥 씨 공 칠 근처에 여자 세 명이 있어요. 할머니와 여자아이, 저예요. 비상등만 켜져 있고 물이 계속 들어와요. 계단으로 나갈 수 없어요.

신규 사건 요약·확인 사항·원문은 수작업으로 구성한 seed다. 실제 AI 분석을 실행한 경우에만 작업 ID·사용 모델·입력 hash·원 응답·실제 전사와 분석 초안을 별도로 공개한다. 분석 실패·미실행이면 그 상태를 그대로 표시한다. seed의 대본을 전사 정확도 증거로 사용하지 않는다. 실제 DSP 처리가 지각적 개선·의미 복원·화자분리를 보장하지 않는다. 영상 프레임 분석과 화자분리는 현재 미구현이다.

## 공간·경로와 미래 통합

`/spatial/`의 더포엠 역삼 공간 목업과 `/routes/`의 관악→신림 OSM·과거 침수 경로는 각각 별도 메뉴에서 설명한다. 이 가상 지하주차장과 같은 장소라고 주장하지 않으며 실시간 최적 출동 또는 공식 지자체 3D 연결을 구현했다고 말하지 않는다. 경로의 네트워크·과거 침수 출처·엔진 조건·경로 불가 검사는 기존 자료를 보존한다.

향후에는 현장캠·CCTV·기상·현재 통제/침수·지자체 3D 건물·공공데이터를 출처·라이선스·관측 시각·좌표계·버전과 함께 통합하는 연구가 필요하다. Codex가 정기 수집과 정규화, 품질 검토 이력을 누적하고 새 데이터·분석 개선을 재평가하도록 하는 운영 계획이다. 무검토 자동 수집, 학습 완료, 실시간 공공 3D 대응은 현재 구현으로 주장하지 않는다. 논문 자체의 평가 수치는 우리 서비스의 구난 효과 증거가 아니다.

기존 10사건·20보고·4팀의 원문·이력·배정 블록은 그대로 보존하고 신규 2사건·10보고·1팀만 배열 끝에 추가한다. 기존 DB를 초기화하거나 seed로 자동 덮어쓰지 않는다. 공유 DB에 신규 ID를 추가하는 작업과 실제 브라우저·AI·미디어 검증은 메인의 통합 범위다.
