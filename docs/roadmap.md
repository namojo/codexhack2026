# 아직 여기 — 공개·실시간 정보 연계 To-Do

현재 구현은 합성 신고 원문, 실제 합성 사진·WAV, 실제 모델 분석 초안, 담당자 확인, 공유 사건 상태 및 부분 구조 완료 차단을 제공한다. 별도 공간 목업과 출동 경로 검토는 독립 사례이며 가상 한빛복합센터와 좌표를 자동 연결하지 않는다.

| 다음 작업 | 구현 방향 | 완료 기준 |
|---|---|---|
| Codex 보조 공공데이터 누적 | 공개 도로·침수흔적·건물·시설 데이터를 정기 수집, 정규화, 중복 제거하고 변경분을 누적한다. 수집 및 변환 코드를 Codex로 보조하되 라이선스·원문·관측/수집 시각·좌표계·버전·체크섬·품질 검사를 보존한다. | 버전별 재현, 실패 시 마지막 검증본 유지, 담당자 승인 후 검색/지도/평가셋 갱신 |
| 3D 건물·층 지도 | 서울시·지자체·관공서 공개 자료의 층·출입구·기둥 ID를 좌표와 연결하고 위치 후보를 대조한다. | 실제 사용 가능한 공개 자료의 권리·좌표·층 검증, 모호한 후보와 담당자 확인 표시 |
| 현장 캠·CCTV·기상·침수 관측 | 시간·출처·지연과 함께 통합하고 추가 신고 시 인계 초안을 다시 만든다. | 최신성과 접근 권한 표시, 오래된 관측 경고, 자료 없이 안전 경로 확정 금지 |
| 음성·저조도 이미지 평가 | 원음/DSP 처리음의 전사 오류, 저조도 기둥 판독, 잔류 인원 누락, 검토 시간 평가 | 별도 정답셋·모델·환경·수정률·실패 사례 기록. 화자 분리·동영상 분석은 별도 구현 및 검증 |
| 현장 운영 검증 | 전문가와 수동 대조 대비 누락률·인계 갱신 지연·담당자 검토 시간을 비교 | 모의훈련 결과와 실제 운영 효과를 구분. 자동 완료·동일인 확정·실제 신고 발송 없음 |

데이터 누적은 무조건 모델 학습을 의미하지 않는다. 먼저 검증된 버전의 검색·검색증강·공간 대조와 회귀 평가를 갱신하고, 재학습은 별도 데이터 권리·성능·비용 판단 후 진행한다. 현재 공개 경로 예제의 과거 침수흔적은 실시간 수심이나 통행 상태가 아니다.

## 연구 근거

- [NIST Public Safety Audio Quality](https://www.nist.gov/programs-projects/public-safety-audio-quality): 공공안전 음성의 소음·명료도 문제와 평가 방향. 이번 DSP의 화자 분리나 정확도 개선을 입증하는 자료가 아니다.
- [Gupta et al., xBD (2019)](https://arxiv.org/abs/1911.09296): 재난 전후 위성 영상의 건물 피해 데이터셋. 이미지·공간정보 결합 방향의 근거이며 실내 인원 위치 인식 근거가 아니다.
- [Chen et al., DisasTeller, Nature Communications (2026)](https://www.nature.com/articles/s41467-025-68216-z): 비전 언어 모델의 피해 평가·경보·자원 배분 보고 지원 연구. 초기 오류 전파와 사람 검토 필요성도 보고한다. 우리 서비스의 생명 구조 효과를 증명하지 않는다.

원문을 2026-10-09 확인했다. 현재 구현·실제 호출·합성 재생의 증거는 각각 검증 기록에서 구분한다.
